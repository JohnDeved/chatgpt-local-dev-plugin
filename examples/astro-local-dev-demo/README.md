# Local Orbit

A self-contained Astro dashboard demonstrating a local open, build, and browser-inspection workflow.

## Commands

```sh
npm install
npm run check
npm run build
npm run dev -- --host 127.0.0.1 --port 4321
```

Open `http://127.0.0.1:4321`. No external images, fonts, APIs, or CDNs are used.
